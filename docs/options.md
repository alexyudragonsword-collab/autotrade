# 期权交易指南

系统支持期权**买方与卖方（sell-to-open）**，覆盖 IBKR 与富途两个真实券商 + Paper 模拟盘。本文是期权功能的完整说明：符号格式、风控两档、到期守护、TV 信号、内置策略与券商细节。

> 范围说明（设计上明确排除）：期权**回测**（无免费历史数据源）、希腊字母/IV、组合腿单（跨式/价差等需逐腿下单）、行权/被行权的主动处理（被行权后的正股变动经持仓同步自然体现）。

## 1. 合约符号

规范格式：`{市场}.{正股代码}|{到期日YYYYMMDD}|{C或P}|{行权价}`

```
US.AAPL|20250919|C|230      # AAPL 2025-09-19 到期、行权价 230 的 Call
HK.00700|20250929|P|360     # 腾讯 Put
```

- 保留 `US.` / `HK.` 市场前缀，所以按市场路由券商的逻辑与股票一致；
- 全系统（信号、订单、持仓、守护、绩效）都用这一格式；
- **乘数（multiplier）**全链路核算：美股期权默认 100，港股期权从券商快照取（取不到用 `HK_OPTION_MULTIPLIER_DEFAULT`，默认 100）。风控名义、成交盈亏、账户净值、浮动盈亏全部乘以乘数。

## 2. 开启期权交易

后台「风控设置」→ 期权卡片：

| 配置 | 默认 | 说明 |
|---|---|---|
| 期权交易开关 `options_trading_enabled` | 关 | 关闭时一切期权单被 `options_enabled` 规则拒绝 |
| 允许裸卖 `allow_naked_selling` | 关 | 卖方风控档位切换，见下节 |
| 空头名义上限 `max_short_option_notional` | 100,000 | 裸卖档的总名义约束 |
| 到期提醒天数 `expiry_warn_days` | 3 | 到期前 N 天开始每日提醒 |
| 到期前自动平仓 `auto_close_before_expiry` | 关 | 开启后到期前 1 日自动市价平仓 |

## 3. 卖方风控两档

期权卖单在常规规则（kill switch、白名单按**正股**匹配、限额等）之外，还要过卖方专属检查：

**默认档——CoveredOrSecuredRule（备兑/现金担保）**

- 卖 Call：需持有足额正股备兑，`正股数量 ≥ (已有空头Call张数 + 本单张数) × 乘数`；
- 卖 Put：需现金担保，`现金 ≥ 已占用担保 + 行权价 × 乘数 × 本单张数`；
- 现金取实时账户查询（5 秒超时）→ 净值快照兜底 → 都取不到则 **fail-closed 拒单**（宁可错杀）。

**裸卖档——NakedNotionalRule（显式开启 `allow_naked_selling` 后）**

- 不再要求备兑/担保，改为约束总名义：`现有空头名义 + 行权价 × 乘数 × 本单张数 ≤ max_short_option_notional`。

两档共同的宽免：**买入平空视为减风险操作**，不受仓位/敞口限额约束——保证任何时候都能平仓离场。

## 4. 到期守护与持仓守护

- **到期守护**（每 4 小时运行）：剩余天数 ≤ `expiry_warn_days` 的持仓每日提醒一次（同日去重）；开启自动平仓后，到期前 1 日以市价平仓（`source=expiry_guard` 信号留痕，dedup 幂等不会重复平）。
- **持仓守护**（每分钟巡检）对空头持仓方向自动反转：价格**上涨**超阈值 = 止损买回；移动止损用**低水位**（权利金收缩到低点后反弹超阈值即买回锁定利润）。

## 5. 下单入口

**手动下单**（订单页 / 期权链页）：symbol 填完整期权符号，或在期权链页点击目标合约自动预填（默认限价 = 买卖中间价）。表单会解析显示合约要素；卖出无持仓即为卖方开仓（收权利金），界面有相应提示。

**期权链页面**：选择在线的 IBKR/富途账户 → 输入正股 → 选到期日 → 行权价矩阵（Call 买/卖/最新/OI | 行权价 | Put ...，ATM 高亮）→ 点击下单。Paper 账户无链数据属正常（见 §7 的模拟验证姿势）。

**TradingView 告警**：在标准字段外加三个可选字段（出现任一则三者必填）：

```json
{
  "secret": "...", "alert_id": "{{timenow}}-aapl-put",
  "strategy": "my_option_strategy",
  "symbol": "AAPL", "exchange": "NASDAQ",
  "action": "sell", "qty": 1, "order_type": "limit", "price": 2.35,
  "expiry": "2025-09-19", "strike": 230, "right": "P"
}
```

`expiry` 兼容 `YYYY-MM-DD` 与 `YYYYMMDD`；`right` 为 `C`/`P`。CN 市场不支持期权。

## 6. 内置期权策略

三个内置策略均为"到期区间 + 虚值比例"选合约、"临近到期先买回、下轮开新仓"的滚动模式（单轮单向，避免开平竞态）。公共参数：`otm_pct`（虚值百分比，默认 5）、`min_dte`/`max_dte`（选合约的到期区间，默认 20~45 天）、`roll_dte`（剩几天触发滚动买回，默认 3）。

| 策略 | 行为 | 专属参数 |
|---|---|---|
| **CoveredCall 备兑开仓** | 持有正股且无空头 Call 时卖出虚值 Call，张数 = 正股可备兑上限 | `max_contracts`（0=按正股自动） |
| **CashSecuredPut 现金担保卖 Put** | 无空头 Put 且现金足以担保时卖出虚值 Put；被行权接货后正股由你处置（不自动卖 Call） | `contracts`（默认 1） |
| **WheelStrategy 车轮** | 正股足额 → 备兑 Call 腿；无正股 → 现金担保 Put 腿；被行权后下轮自动换腿循环 | `put_contracts`（默认 1） |

绑定方式与股票策略相同：策略管理 → 选类 → symbols 填**正股**（每个正股独立运行一轮）→ cron 运行时间 → 账户。策略产生的开平动作转成信号进统一管道，**卖方两档风控照常把关**；`signal_only` 模式下只提醒不下单。

策略侧的现金检查只覆盖本标的新仓，账户级担保总额由风控 `CoveredOrSecuredRule` 权威把关——两层检查是有意的冗余。

## 7. 模拟验证的推荐姿势

**Paper 执行 + 真实券商链报价**：期权策略的链数据优先取执行账户，执行账户不支持（paper）时自动借用任一在线真实券商（IBKR/富途）的链。所以只要 IBKR 或富途网关在线（模拟环境即可），就能用 paper 账户全真模拟期权策略：真实合约、真实报价、模拟成交、完整风控——上实盘前务必先这样跑一段时间。

## 8. 券商细节

**IBKR**
- 期权合约经 `qualifyContracts` 校验（按 symbol 缓存）；链用 `reqSecDefOptParams`（10 分钟缓存），报价分批节流并用 `strikes_around` 限制档位数，避免触发 IB pacing 限制；
- IB 返回的期权 avgCost 是**每张**口径（含乘数），系统入库时已折算为每股口径，与全系统一致。

**富途**
- 美股期权代码可直接构造（`US.AAPL250919C230000`），双向可逆；
- **港股期权代码不可构造**（缩写命名无规律），系统在查询期权链时建立双向缓存——如果重启后直接对 HK 期权下单提示找不到代码，先到期权链页查一次该正股的链即可；
- 乘数取自快照的 `option_contract_size` 字段，取不到用默认值。

## 9. 常见问题

- **卖单被拒"现金担保不足"但账户明明有钱**：可能是现金查询超时走了 fail-closed。检查券商网关连通性；净值快照（每 4 小时）落库后会作为兜底。
- **期权链页空白**：确认所选账户在线且是 IBKR/富途（paper 无链数据）；HK 标的确认 OpenD 有期权行情权限。
- **期权策略没动作**：看信号日志与策略运行日志——最常见原因是"已有有效空头持仓，本期不加仓"（设计如此）或选不出满足 dte/虚值条件的合约。
- **被行权了会怎样**：持仓同步（每分钟）会把正股/期权变动反映进来；WheelStrategy 下轮运行自动换腿，其他策略按新持仓状态继续。
