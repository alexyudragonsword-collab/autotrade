# Web 后台使用手册

登录后左侧共 12 个页面。右上角可一键切换中文/English（记住选择），本文按中文界面描述。

## 典型工作流

```
选股器（发现标的）──▶ 回测中心（验证策略）──▶ 策略管理（绑定实盘）
                                                  │ 先 signal_only 观察
                                                  ▼
仪表盘/信号日志（日常监控）◀── 通知渠道 ◀── live 实盘运行
```

## 各页面说明

### 📊 仪表盘
交易总开关（= kill switch 的反面，关掉即全局停止下单）、今日信号/订单/风控拦截计数、券商连接状态（在线/离线、净值）、自选关注列表、最近信号与订单。WebSocket 实时刷新，无需手动刷新页面。

### 📡 信号日志
每一条进入系统的信号（TV 告警 / 本地策略 / 手动 / 守护触发）及其最终状态：已接收→已下单→已执行，或重复（幂等丢弃）/风控拦截/已拒绝。**排查"为什么没下单"从这里开始**：状态列 + 说明列会写明被哪条风控规则拦截。

### 📋 订单持仓
- 订单 Tab：全部订单及状态（可按状态筛选）；「手动下单」按钮——手动单同样经过风控并留痕；
- 持仓 Tab：各账户持仓、成本、最新价、浮动盈亏；期权持仓显示乘数，空头数量为负并着色。

### 🎯 期权链
选择在线的 IBKR/富途账户 → 输入正股（如 `US.AAPL`）→ 选到期日 → 行权价矩阵（Call 区 | 行权价 | Put 区，ATM 高亮）。点击任意合约弹出下单框，自动预填合约符号与限价（买卖中间价）。详见 [options.md](options.md)。

### 🧠 策略管理
策略配置 = 一条"信号来源 → 执行方式"的绑定：

| 字段 | 说明 |
|---|---|
| 名称 | **TV 告警里 strategy 字段必须与此完全一致**才会匹配 |
| 本地策略类 | 留空 = 纯接收 TV 信号；选择内置/自定义类 = 本地定时驱动 |
| 模式 | `signal_only` 只提醒不下单（**新策略先用这个**）/ `live` 真实下单 |
| 账户 | 执行券商账户 |
| 默认数量 | 信号未携带 qty 时使用 |
| 监控标的 / cron / 周期 | 本地策略专用：跑哪些标的、何时跑（北京时间 cron）、用什么 K 线周期 |

每行的「运行」按钮可立即手动触发一次本地策略（补跑/测试用，幂等不会重复下单）。

### ✏️ 策略编辑器
在线写 Python 策略：左侧列表（内置策略可「派生」出可编辑副本），右侧代码区。保存前自动编译 + 合成行情试跑，把运行期错误挡在保存前；保存即热加载，立刻可在回测/策略管理中使用。写法详见 [strategy-development.md](strategy-development.md)。

### 🔍 选股器
结构化条件（市场、基本面 PE/PB/市值区间）+ 技术面表达式（如 `close > SMA(close, 20) and RSI(close, 14) < 30`）。可定时运行并推送结果。结果列表支持一键：加入自选 / 发起组合回测。

### 📈 回测中心
左侧配置（策略/参数/市场/周期/标的/区间/初始资金），右侧结果：指标卡（总收益/年化/夏普/最大回撤/胜率/α）、权益曲线 + 基准（等权买入持有）+ 回撤、月度收益热力表、K 线走查（单标的时逐笔标注买卖点）、交易明细。参数写成数组即触发**参数扫描**（如 `{"fast":[5,10,20]}`），结果按组合排名。「导出报告」生成自包含 HTML 可离线分享。历史记录保留所有回测可随时回看。

### 💰 绩效分析
实盘已实现盈亏按**策略 / 账户 / 标的**三维归因（盈亏、平仓次数、胜率、手续费），每日盈亏柱状图，账户净值曲线（每 4 小时自动快照）。

### 🛡️ 风控设置
所有风控参数即改即生效：kill switch、标的白名单、单笔金额上限、单标的持仓上限、总敞口上限、日订单数、日亏损上限、交易时段校验；持仓守护（止损/止盈/移动止损百分比）；期权卡片（开关、裸卖档、名义上限、到期提醒/自动平仓）。**裸卖开关带警告文案，请确实理解卖方风险后再开。**

### 🔔 通知设置
四渠道（Telegram / 邮件 / 企业微信 / 钉钉）各自配置 + 测试按钮；每渠道可设最低级别（INFO/WARN/ERROR）和路由规则（只接收指定策略/账户的消息；系统级事件始终全渠道投递）。

### ⚙️ 系统设置
Webhook 地址与随机 token（可轮换）、TV 告警模板一键复制、券商账户管理（增删/启停多账户，即时生效）、Telegram 机器人 chat_id、佣金费率等。

## 移动端

页面为响应式布局，手机浏览器可用；日常移动监控更推荐 Telegram 机器人：`/status` `/pos` `/orders` `/run 策略名` `/kill` `/resume`。
